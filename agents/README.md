# Agents

Agentes especializados do NextFood.

## Inicialmente previstos

- `architect`: valida decisões e impacto arquitetural.
- `planner`: transforma requisitos aprovados em tarefas rastreáveis.
- `frontend`: implementa UI e fluxos React/Next.js.
- `backend`: implementa serviços, APIs e regras de domínio.
- `qa`: cria e executa testes.
- `security`: revisa autorização, multi-tenancy, exposição de dados e vulnerabilidades.
- `reviewer`: faz revisão final de aderência a requisitos e qualidade.

O orquestrador deve chamar apenas os agentes necessários para cada mudança.
